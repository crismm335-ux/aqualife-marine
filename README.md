# AquaLife Marine 🐠

Jogo de simulação de aquário marinho no navegador: monte o aquário, cicle a água, cuide de peixes, corais e equipamentos.

**Jogar:** https://crismm335-ux.github.io/aqualife-marine/

## Instalar como app no PC
Abra o link no Chrome ou no Edge e clique no ícone de instalar na barra de endereço (ou menu ⋮ › "Transmitir, salvar e compartilhar" › "Instalar página como app").
O jogo abre em janela própria, ganha ícone na área de trabalho e funciona até sem internet.

## Atualizar o site
`python3 build.py <jogo.html> <modelo-index.html>` gera o `index.html` com o manifesto e o service worker.
